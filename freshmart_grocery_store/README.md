# FreshMart — Online Grocery Store

A responsive front-end grocery store demo built with HTML, CSS and vanilla JavaScript.

## Run in VS Code
1. Extract `freshmart_grocery_store.zip`.
2. Open the extracted `freshmart_grocery_store` folder in Visual Studio Code.
3. Open `index.html` in your browser, or install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

## Features
- Responsive grocery storefront
- Product cards and category filters
- Search products by name or category
- Add items to cart and change quantities
- Automatic cart count and subtotal
- Demo checkout message

## Project structure
- `index.html` — page structure
- `css/style.css` — styling and responsive layout
- `js/app.js` — products, filters and cart logic

## Note
This is a front-end demo. Checkout does not process real payments or save orders. To launch a real store, connect a backend, database, delivery workflow and payment provider.
